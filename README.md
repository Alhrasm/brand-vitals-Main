# Brand Vitals — Website

Marketing website for **Brand Vitals**, a data-driven growth and performance marketing agency based in Cairo, Egypt, serving Egypt and the wider MENA region.

Static, multi-page site (no build step). Bilingual English / Arabic with full RTL support, dark and light themes.

## Pages
`index.html` (home) · `solutions.html` · `work.html` · `products.html` (Growth Packages) · `about.html` · `careers.html` · `blog.html` · `contact.html` · `privacy.html` · `404.html`

## Structure
```
assets/
  css/main.css     design system + all styles
  js/main.js       theme, i18n, reveal, counters, consult modal
  img/             logo, favicon, platform marks
```

## Run locally
Any static server works, e.g.:
```bash
npx serve . -l 3000
```
Then open http://localhost:3000
